# 第 12 章：生产安全清单

- 密钥只在必要的最短生命周期内存在，释放前考虑清零；
- 私钥存放在安全区域或安全芯片中，禁止写入普通日志和崩溃转储；
- TLS 默认启用证书链、用途、主机名和时间校验；
- 认证失败、证书错误、重放/计数器回滚和随机数不可用都必须进入明确的故障状态；
- 版本升级要跟踪 OpenSSL 安全公告、发行版补丁和 provider/FIPS 配置变化；
- 把教学用自签名证书、固定口令、玩具 provider 和 `SSL_VERIFY_NONE` 从生产构建中排除；
- 为证书轮换、设备吊销、时间异常、网络抖动和断电恢复设计可测试的状态机。

完成教程后，建议用一个真实设备通信模块复盘这份清单，并形成威胁模型、密钥生命周期文档和发布前测试报告。

## 实验：发布前自审

在提交产品代码前，至少执行：

```sh
./scripts/verify_tutorial.sh
rg -n 'SSL_VERIFY_NONE|EVP_MD_fetch|OSSL_PROVIDER_load' .
```

对每个 `SSL_VERIFY_NONE` 逐处说明它是否仅存在于测试代码；对每个 provider/fetch 调用记录算法属性、配置来源和失败处理。最后把证书轮换、随机数不可用、错误主机名和断电恢复加入目标设备的测试报告。
