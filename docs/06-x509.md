# 第 6 章：X.509、PKI 与证书验证

证书验证至少包含：链构建、信任根、签名校验、有效期、用途和名称匹配。只调用 `SSL_CTX_set_verify` 而不设置可信根和主机名校验，不能算完成了服务端身份验证。

## 应用侧对象

- `X509_STORE`：可信证书和验证参数；
- `X509_STORE_CTX`：一次具体验证操作的上下文；
- `SSL_CTX_set1_verify_cert_store`：把证书验证策略接入 TLS；
- `X509_VERIFY_PARAM_set1_host`：设置 DNS 主机名匹配规则。

## 本地 PKI 实验建议

先用 CLI 建立 Root CA、签发服务端证书，再分别测试过期、错误 SAN、错误用途、缺失中间证书和错误信任根。不要用 `SSL_VERIFY_NONE` 掩盖验证问题；它只适合本教程第 7 章的本地状态机演示。

仓库中的最小 C 实验会把自签名证书加入信任库，并单独设置主机名参数：

```sh
cmake --build build --target openssl_x509_verify
ctest --test-dir build -R x509_verify --output-on-failure
```

成功用例使用 `localhost`，负面用例使用 `wrong.example`；两者都必须执行，才能证明名称校验确实生效。
